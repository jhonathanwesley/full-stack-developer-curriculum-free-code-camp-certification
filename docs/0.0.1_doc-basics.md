## Tags & their **Syntax**

> Heading Tags:

```html
1. <h1>Heading 1</h1>
2. <h2>Heading 2</h2>
3. <h3>Heading 3</h3>
4. <h4>Heading 4</h4>
5. <h5>Heading 5</h5>
6. <h6>Heading 6</h6>
```

> Image tag (*void tag*)

```html
<!-- Tag de imagem vazia -->
<img>

<!-- Tag com propriedades de: Fonte 'src', Descrição alternativa 'alt' e  -->
<img src="" alt="" style="">
```

> Anchor element: Permite criar links para outras páginas

```html
<a></a>

<a href="http://137.131.224.95/cars/">
```
